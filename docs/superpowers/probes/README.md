# UI probes

Probes live in `apps/e2e/probes/`, one file per claim, run by the kit's runner:
`node ~/.claude/fwd/skills/ui-probe/probe.mjs apps/e2e/probes/<name>.mjs --base http://localhost:3010 [--expect-fail]`.

| Probe                           | Proves                                                                                                                                                                                                                                                                                                | Needs                                                                                                                 | Fails when                                                                                                                      |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `cobill-heading-fit.mjs`        | A two-name co-billed event heading shows both names in full: at most three lines, type stepping 34 → 30 → 26px, no clamp, no horizontal overflow. Needs a layout engine: jsdom has none.                                                                                                              | `PROBE_EVENTS` (comma list of event ids; default is the longest real pair and a scratch-only long pair)               | `FIT_STEPS` in `CoBilledHeading.tsx` is emptied: the long pair clamps at three lines.                                           |
| `venues-filter-tap-through.mjs` | On a phone, pressing "Nearest first" in the Venues Sort sheet selects it: the sheet is still open when the click lands, and the click never reaches the venue card link under the option. Needs a layout engine and real touch.                                                                       | A signed-in dev server (Venues has at least one card behind the sheet)                                                | The `isDesktop` gate on `FilterPopover` in `VenueFilterBar.tsx` is removed: the hidden popover closes the sheet on pointerdown. |
| `global-error-retry-theme.mjs`  | The root error page (`global-error.tsx`) keeps its theme through four presses of Try again (`data-theme` and `--bg` on `<html>` match first paint), and one press on Go home leaves it. | `artist-preview-close.mjs`      | The MusicBrainz-only artist preview has one visible Close with a 44px hit box that closes it in one press; focus opens on Follow; the plate is 84px on the phone sheet and 96px on the desktop card; a long name ends before the Close; no horizontal overflow.
