# #1053 — Re-key event dedup to headliner + show_time Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Collapse duplicate event rows caused by billing/title variants of the same show by moving the dedup key from `(venue_id, date, canonical_title)` to `(venue_id, date, canonical_artist, show_time)` with `NULLS NOT DISTINCT`, plus a one-shot prod consolidation backfill.

**Architecture:** Expand/contract rollout mirroring #821/#0044. A consolidation SQL script collapses existing dupe clusters (runs to completion in each env _before_ the migration builds the new index). Migration 0057 swaps the partial UNIQUE index. `crawl.ts` swaps the in-memory dedup key + ON CONFLICT target in the same PR/deploy. `canonical_title` stays on the table as a display/search column.

**Tech Stack:** Drizzle ORM 0.45.2, Postgres 16 (local/CI/Neon — `NULLS NOT DISTINCT` requires PG15+), pnpm + Turborepo, Vitest integration tests.

> **Implementation note (Task B):** Drizzle 0.45.2 exposes `.nullsNotDistinct()` only on `UniqueConstraintBuilder`, **not** on the `IndexBuilder` used for partial unique indexes. So the schema (`events.ts`) models the column set + `WHERE status='upcoming'` predicate _without_ `.nullsNotDistinct()`, and the `NULLS NOT DISTINCT` clause lives in the raw SQL of migration 0057 — the authoritative source. The `.nullsNotDistinct()` calls shown in Step 3 below reflect the original plan, not the shipped schema; see `packages/db/src/schema/events.ts` for the actual approach.

**Key helper.** The dedup key must combine `canonical_artist`, `date`, and a normalized `show_time`. Postgres `time` always returns `HH:MM:SS`; extractor input may be `H:MM`/`HH:MM`/`HH:MM:SS` or null. Add a module-level helper so the in-memory key matches the stored value on both sides:

```ts
// Normalizes a show_time string to the Postgres `time` output form
// (HH:MM:SS) for building the in-memory dedup key. Null/empty/unparseable
// → '' — which groups with the DB's NULL under NULLS NOT DISTINCT. DB rows
// return 'HH:MM:SS' already, so this is idempotent on the existingMap side.
function showTimeKey(raw: string | null | undefined): string {
  if (!raw) return ''
  const match = /^(\d{1,2}):(\d{2})(?::(\d{2}))?/.exec(raw.trim())
  return match
    ? `${match[1].padStart(2, '0')}:${match[2]}:${match[3] ?? '00'}`
    : ''
}

function dedupKey(
  canonicalArtist: string,
  date: string,
  showTime: string | null | undefined,
): string {
  return `${canonicalArtist}|${date}|${showTimeKey(showTime)}`
}
```
