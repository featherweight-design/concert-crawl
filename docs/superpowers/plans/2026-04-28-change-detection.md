# Change Detection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two-layer change detection to `crawlVenue()` — skip entire crawls when the page hash is unchanged, and skip individual DB writes when event content is unchanged — to eliminate redundant LLM calls and unnecessary DB writes.

**Architecture:** Layer 1 computes a SHA-256 hash of the page HTML (minus scripts/styles) and compares it to the last successful crawl run; if it matches, the crawl exits immediately. Layer 2 computes a per-event content hash (`title|artist|date|doorsTime|showTime`) and skips DB writes for unchanged events; changed verified events trigger an admin alert instead of silently overwriting.

**Tech Stack:** Node.js `crypto` (built-in), Drizzle ORM, Vitest, PostgreSQL

```ts
import { createHash } from 'crypto'

export function hashPage(html: string): string {
  const stripped = html
    .replace(/<script\b[^>]*>[\s\S]*?<\/script>/gi, '')
    .replace(/<style\b[^>]*>[\s\S]*?<\/style>/gi, '')
  return createHash('sha256').update(stripped).digest('hex')
}

export function hashEvent(fields: {
  title: string
  artist: string
  date: string
  doorsTime?: string | null
  showTime?: string | null
}): string {
  const str = [
    fields.title,
    fields.artist,
    fields.date,
    fields.doorsTime ?? '',
    fields.showTime ?? '',
  ].join('|')
  return createHash('sha256').update(str).digest('hex')
}
```

```ts
let eventsInserted = 0
if (normalizedEvents.length > 0) {
  // Compute sourceHash for each extracted event
  const eventsWithHashes = normalizedEvents.map((event) => ({
    ...event,
    sourceHash: hashEvent({
      title: event.title,
      artist: event.artist,
      date: event.date,
      doorsTime: event.doorsTime,
      showTime: event.showTime,
    }),
  }))

  // Load existing events for this venue to compare hashes
  const existingRows = await db
    .select({
      artist: events.artist,
      date: events.date,
      title: events.title,
      sourceHash: events.sourceHash,
      verified: events.verified,
    })
    .from(events)
    .where(eq(events.venueId, venueId))

  const existingMap = new Map(
    existingRows.map((e) => [`${e.artist}|${e.date}`, e]),
  )

  // Notify admin when a verified event's source data has changed
  const changedVerified = eventsWithHashes.filter((e) => {
    const existing = existingMap.get(`${e.artist}|${e.date}`)
    return existing?.verified === true && existing.sourceHash !== e.sourceHash
  })

  if (changedVerified.length > 0) {
    await db.insert(notifications).values(
      changedVerified.map((e) => ({
        type: 'admin_alert' as const,
        category: 'crawl.verified_event_changed',
        title: `Verified event may have changed: ${venue.name}`,
        body: `Verified event may have changed: "${e.title}" at ${venue.name} on ${e.date}`,
        metadata: JSON.stringify({ venueId, crawlRunId: id }),
      })),
    )
  }

  // Only upsert events that are new or have changed content
  const eventsToUpsert = eventsWithHashes.filter((e) => {
    const existing = existingMap.get(`${e.artist}|${e.date}`)
    if (!existing) return true // new event
    return existing.sourceHash !== e.sourceHash // content changed
  })

  if (eventsToUpsert.length > 0) {
    const eventValues = eventsToUpsert.map((event) => ({
      venueId,
      title: event.title,
      artist: event.artist,
      date: event.date,
      doorsTime: event.doorsTime ?? null,
      showTime: event.showTime ?? null,
      ticketUrl: event.ticketUrl ?? null,
      description: event.description ?? null,
      imageUrl: event.imageUrl ?? null,
      sourceUrl: event.sourceUrl,
      sourceHash: event.sourceHash,
      status: 'upcoming' as const,
      confidenceScore: event.confidence.toFixed(2),
      verified: strategy === 'structured_data',
      extractionStrategy: strategy,
    }))

    const upserted = await db
      .insert(events)
      .values(eventValues)
      .onConflictDoUpdate({
        target: [events.venueId, events.date, events.artist],
        set: {
          title: sql`excluded.title`,
          doorsTime: sql`excluded.doors_time`,
          showTime: sql`excluded.show_time`,
          ticketUrl: sql`excluded.ticket_url`,
          description: sql`excluded.description`,
          imageUrl: sql`excluded.image_url`,
          status: sql`excluded.status`,
          extractionStrategy: sql`excluded.extraction_strategy`,
          confidenceScore: sql`excluded.confidence_score`,
          sourceHash: sql`excluded.source_hash`,
          updatedAt: new Date(),
        },
      })
      .returning()

    eventsInserted = upserted.length
  }
}
```
