# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a theme-aware SVG favicon and Apple touch icon derived from the existing MiniMark geometry.

**Architecture:** `app/icon.svg` is a static SVG file using CSS `prefers-color-scheme` media queries to switch between Electric (dark) and Light token values. `app/apple-icon.tsx` is a Next.js App Router route segment that returns an `ImageResponse` PNG at 180×180 using hardcoded Electric tokens. Both files are auto-discovered by Next.js — no metadata changes required. `themeColor` in `layout.tsx` is corrected from `#000000` to the Electric `bg` value `#070A1A`.

**Tech Stack:** Next.js 15 App Router, `next/og` (`ImageResponse`), Vitest, SVG

import { readFileSync } from 'fs'

import { fileURLToPath } from 'url'
import { describe, it, expect } from 'vitest'

const dir = dirname(fileURLToPath(import.meta.url))
const svgContent = readFileSync(resolve(dir, 'icon.svg'), 'utf-8')

describe('icon.svg', () => {
  it('contains dark mode media query', () => {
    expect(svgContent).toContain('prefers-color-scheme: dark')

  it('contains Electric dark surface token', () => {
    expect(svgContent).toContain('#171D3A')
  })

  it('contains Light surface token', () => {
    expect(svgContent).toContain('#E8EDF6')
  })

  it('contains signal element', () => {

})

### Step 2.3: Create `apple-icon.tsx`

```tsx
// apps/web/src/app/apple-icon.tsx
import { ImageResponse } from 'next/og'

export const size = { width: 180, height: 180 }
export const contentType = 'image/png'

export default function AppleIcon() {
  return new ImageResponse(
    <svg
      width="180"
      height="180"
      viewBox="0 0 48 48"
      xmlns="http://www.w3.org/2000/svg"
    >
      {/* Background */}
      <rect width="48" height="48" rx="10" fill="#171D3A" />
      {/* Signal ring */}
      <circle cx="34" cy="14" r="9" fill="#FF7BD4" opacity="0.22" />
      <circle cx="34" cy="14" r="5" fill="#FF7BD4" opacity="0.45" />
      <circle cx="34" cy="14" r="3" fill="#7AE6FF" />
      {/* Dot trail */}
      <circle cx="14" cy="38" r="1.6" fill="#E8F3FF" opacity="0.45" />
      <circle cx="18" cy="34" r="1.6" fill="#E8F3FF" opacity="0.52" />
      <circle cx="22" cy="30" r="1.6" fill="#E8F3FF" opacity="0.59" />
      <circle cx="26" cy="26" r="1.6" fill="#E8F3FF" opacity="0.66" />
      <circle cx="30" cy="22" r="1.6" fill="#E8F3FF" opacity="0.73" />
      <circle cx="34" cy="18" r="1.6" fill="#E8F3FF" opacity="0.80" />
      <circle cx="14" cy="32" r="1.6" fill="#E8F3FF" opacity="0.87" />
    </svg>,
    { ...size },
  )
}
```
