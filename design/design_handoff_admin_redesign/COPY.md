# Admin Redesign: Strings for Copy Review

Admin copy is exempt from the em-dash rule, but not from the locked vocabulary. Every string on the boards is a **draft**. Copy is the copy-writer's call (`copy-review` skill), not Design's, so change strings in place and never send the handoff back to Design over wording. The canvas (https://claude.ai/artifact/XggqBuiujza1vegiCGDQnd) shows each one in context.

## Admin: new labels and lines

- **Needs you:** the kind labels (SHOW, VENUE, ARTIST, EVENT, PRICES, BUG), each answer button, the likely-cause lines, and "N decisions. Soonest for fans first."
- **Health:** the tile labels, "Done for you overnight", and the tile footers.
- **Venues:** the five tab names, "How we read it", "What's normal here", and the ⋯ menu lines.
- **Add a venue:** the step names, "Venues people asked for", the Ask the venue email draft, "Paused: waiting on permission", the Test before live lines, the guide hints, and the hero setting names (Street, Outdoor, Arena, Theater, Club, Gallery).
- **Events, Artists, Prices:** "On Concert Crawl", "On the venue's site", "Edit price", "Publish and next", "Looks right", "No photo for now", "Not an artist", and the Mark cancelled dialog.
- **People:** "Handles, not emails…", the role note, "Make @x an admin?", the code form hints, the code menu lines, "Revoke X?", and "Reactivate…".
- **Feature flags:** the page subtitles, "WHO SEES IT HERE", "STAGING CHECK", the Mark verified checklist, and "Turn X on for everyone?".
- **Operations:** the feedback filter names, the Reply panel note, "Only emails we still send…", and the empty and loading lines.
