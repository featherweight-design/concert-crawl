WHERE THE MESSAGE GOES
Row: it replaces the second line, wrapping to two lines if it must; the row grows. Page, preview and desktop rail: it replaces the pitch line under the Follow. The optimistic Following always falls back to Follow first.
TWO COLOURS, BOTH EXISTING
--danger when this act cannot be followed (404, 409). --warning when trying later will work (429, 503). Each with the alert glyph, so colour is never the only signal.
HOW LONG IT STAYS
Until the next tap on that Follow, a new query, or leaving the page. 429 shows the retry time from Retry-After in the viewer's local time; every other row hits the same limit, so it repeats the same time.
