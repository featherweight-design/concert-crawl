Concert Crawl · design · Nov 11

The invite poster

A Letter-size poster for venues, record shops and bars. It says what Concert Crawl is in one line, names the venues it covers, and puts a 4.5 in QR on white so it scans across a dark room. Each poster carries one shared code with a set number of seats.

The poster

Night is the main design: the real CCMark, large, with its trail climbing toward the halo, the headline in the app’s cyan-to-pink, and a white QR card. A 0.3 in paper frame is designed in, because most printers can’t print to the edge and would leave an uneven white margin anyway. Paper is the one-ink version for black-and-white printers, photocopies and colored paper. Tear-off tabs are optional on either.

At a glance

Every Denver show. One list. is readable from across the room. The venue names under it are the proof, and they’re the names people in that room already know.

Want in

The BETA TESTERS WANTED chip, the LAUNCHING LATER · TESTING NOW line and “Help us test it before launch” say it’s a test before launch, with no date that goes stale on the wall. The seat line (“This poster lets in 50 testers. When the spots are gone, they’re gone.”) makes it scarce.

Get in

The QR opens the invite screen with the code filled in. For people who won’t scan, the short URL and the code are printed beside it, and the tabs carry both.

All poster copy is new and needs copy review: the chip, the launching-later line, headline, sub, “Scan to test it”, the seat line, “No camera? Go to … and enter”, and “Not affiliated with the venues listed.” The venue count and list should come from the live venue table at print time.

Why it scans in a dark bar

The QR gets bigger modules by holding less. Today it encodes the full sign-up URL in mixed case, which forces byte mode and a version 4 code (33 modules). The proposal encodes a short all-caps redirect, HTTPS://CONCERTCRAWL.APP/I/BETA-7K2M-Q9XD, which fits QR’s compact alphanumeric mode: version 3 (29 modules) even at the stronger Q error correction, which survives tape, glare and a scuffed corner. Printed at 4.5 in, each module is about 4 mm.

How I tested: rendered each QR at print size, shrank it to what a 12 MP phone camera sees at each distance, cut the light to 15%, added sensor noise and blur, and decoded it with OpenCV, 8 trials per row. Phone camera apps are better than OpenCV, so real distances run longer, but the gap between today and the proposal holds. Rules the design keeps: black modules on white paper (never inverted, never brand-colored), a 4-module quiet zone, no logo inside the code, and matte paper.

Admin: print a poster

A Posters tab inside Invite codes. Three steps, top to bottom: pick a poster code (or mint one), pick a look, print. The preview on the right is the real sheet at scale, so what you see is what prints. Each code shows seats taken, scans and expiry, so you can see which wall is working. Full codes stay in the list, faded, so you know to replace that poster. In the current B+ style: one ambient glow (the page), a gradient edge only on the selected code.

What changes in code

The data model from PR #79 already fits: max_uses, use_count, label, and the print rules. The changes are mostly the sheet and one route.

  1. Restyle PosterSheet and poster.css to Night and Paper, using CCMark’s geometry and BRAND_COPY.wordmark. Add print-color-adjust: exact so Night prints its background.
  2. Add a short redirect, /i/[code], matched case-insensitively, that sends the visitor to /auth/code?code=…. The QR encodes it in all caps. It can also count scans per code, which the admin list shows.
  3. QR settings: error correction Q, quiet zone 4, drawn 4.5 in wide (3.5 in with tabs). Keep the existing local uqr drawing.
  4. Admin Posters tab with the code list, the inline mint form, the look picker, the tabs switch and the live preview. QR download becomes SVG (sharp at any size).
  5. Copy goes through copy-review, and the poster copy moves into lib/poster/definitions/copy.ts.

Test prints: open design/invite-poster/test-print-night.html (or -paper, -night-tabs) from the project files in Chrome and print at Letter, margins None, Background graphics on. The sample QR points at the proposed /i/ route, so it scans but won’t open a page until that route exists.
